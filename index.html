ABOUT THIS BUILD

Chapter-wise v2.0

This is a functional front-end prototype with chapter and topic filters, two-paper chapter catalogue, difficulty levels, timer, MCQ selection, review flags, scoring and local history. The bundled bank is a starter set and should be expanded and cross-checked against the current DU circular.

AI status: AI Tutor & Problem Solver interface is included. Configure and deploy the secure backend in the backend/ folder, then set its URL in assets/app.js. Never put the provider API key in this repository.

Privacy: attempts are stored in this browser's local storage and are not synced across devices.
